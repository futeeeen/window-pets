# 🐾 Window Pets — 模組化 2D 電子桌寵平台

一個基於 Electron 與 Canvas 構建的**輕量化、高擴充性 2D 桌面電子寵物平台**。擁有極致流暢的去背渲染、防邊界像素溢出（Zero-Bleed）算法，並支援多種智能行為模式與動態外觀無縫熱切換！

為了提供使用者最簡潔、直覺的體驗，專案已經過深度整理，將所有核心代碼模組化封裝至 `src/` 目錄中，使根目錄保持最純淨的狀態，只留下使用者需要直接使用的檔案。

---

## 🚀 快速啟動

本專案已完全配置好所有執行環境，使用者**不需要手動安裝任何環境**（只要您的電腦安裝了 Node.js）。

1. **一鍵啟動**：
   雙擊執行根目錄下的 **`start.bat`** 即可在桌面上召喚您的 Gulpin（綠肚肚）桌寵！
2. **互動與退出**：
   在桌寵上點擊**滑鼠左鍵**可自由拖曳、向空中拋擲（具備重力物理彈跳！）。在桌寵上點擊**滑鼠右鍵**，即可開啟 native 系統選單進行互動與設置，選擇 **`🚪 關閉寵物`** 即可安全退出程式。

## 🎮 豐富的互動與右鍵選單

對著桌寵點選**滑鼠右鍵**，即可開啟強大的系統選單進行多種操作：

* **🍎 互動餵食**：可選擇餵食「蘋果」或「蛋糕」，寵物會張大嘴巴吃掉並露出超滿足的表情！
* **💖 摸摸寵物**：寵物會開心地閉上眼睛並左右快速抖動！
* **🐾 隨機散步模式 (Walk Mode)**：
  * 以 $70\%$ 散步、$30\%$ 定點發呆/睡覺/打哈欠的黃金比例自主活動。
  * 每次起步的方向、終點、漫步距離與速度皆為隨機，步伐無比靈活！
* **🏃 運動模式 (Sports Mode)**：
  * 寵物會持續在螢幕最左邊與最右邊來回折返奔跑。
  * 抵達螢幕邊界時會暫停並做出**開心的扭屁股抖動**，接著轉向繼續前進！
  * 運動中有低機率會因為太累而**當場倒地睡個懶覺**，睡飽後會乖乖爬起來繼續完成運動！
* **🛑 罰站模式 (Stand Mode)**：
  * 寵物會乖乖待在原地，絕不橫向移動。
  * 依然會隨機做原地打哈欠、睡大覺或張大嘴巴扭動等定點動作。
  * **定點隨機轉向**：每次做動作時有 $50\%$ 的機率會水平轉向，在原地好奇地左右觀望！
* **💤 讓牠睡覺 / 喚醒寵物**：強行讓寵物倒地進入睡眠狀態或將其喚醒。
* **📐 尺寸調整**：支援「小 (80x80)」、「中 (110x110)」、「大 (140x140)」三種尺寸，完美適適您的螢幕，且縮放時比例 $100\%$ 恆定，絕對不會因頻繁拖拽或尺寸更換而導致體型變大（已修復 Windows DPI 縮放 Creep 漏洞）。
* **🎭 更換外觀 (Skins)**：
  * **動態熱切換**：本引擎會在您打開選單時**實時讀取** `pets/` 目錄下的文件夾。
  * 點擊即可**在免重啟的情況下秒切外觀**！
  * 切換後會自動將您的喜好記錄在 `src/active_pet.json`，下次啟動時會自動載入您上次的選擇。

## 🎨 創作者指南：如何設計並導入一個新寵物外觀？

我們為創作者提供了一個**極致便利的 2.0 模組化引擎**。如果您想要自己設計一套桌寵外觀，請參照專案內的 AI 專用設計說明書：
👉 [ai_creator_prompt.md](file:///C:/Users/futen/.gemini/antigravity/brain/ec0eeb05-caa0-4c7b-bf57-9c19bfa5f0c1/ai_creator_prompt.md) (您可以直接將其複製給 Midjourney, Stable Diffusion 或 Gemini/Claude 以自動生成完全符合規格的去背精靈圖)。

### 💡 創作者導入三步驟：
1. **建立文件夾**：在 `pets/` 目錄下建立一個全新資料夾，例如 `pets/pikachu/`。
2. **置入精靈圖**：將您的精靈圖命名為 `sprites.png` 並放入該資料夾內。
3. **置入配置文件**：放入一個簡單的 `config.json`，指定中文展示名稱即可：
   ```json
   {
     "name": "Pikachu (皮卡丘)",
     "author": "您的筆名",
     "version": "1.0.0"
   }
   ```
4. **啟動桌寵**：完成！直接右鍵打開選單，**更換外觀 (Skins) 選單中就會立刻出現「Pikachu (皮卡丘)」**，點擊即可瞬間換裝！

*注：如果您不指定 config.json 中的坐標，本引擎將自動使用 **標準 $250 \times 200$ 網格切圖解析器**（5 列 3 行）分割圖片，無需編寫任何裁切坐標！*
