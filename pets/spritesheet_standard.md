# 🎨 Window Pets — 2D 精靈圖 (Spritesheet) 標準設計規範 v2.0 (Redefined)

這是一份專為「動態外觀模組化熱切換引擎」設計的**無設定檔（Zero-Config）標準精靈圖規格說明書**。

本規範之目的在於提供一個**嚴格的、通用的物理與視覺網格框架**。創作者（或 AI 繪圖工具）只需按照本規範輸出名為 `sprites.png` 的精靈圖，即可**直接放入專案資料夾啟動，無需撰寫任何坐標配置文件 (`config.json`)**！引擎會自動進行完美的像素去背、動作切割與重力地板線對齊。

---

## 📐 一、 網格尺寸與影格間距標準 (Grid & Spacing)

精靈圖採用**無縫網格佈局 (Seamless Grid Layout)**，影格與影格之間無空隙，間距為 $0\text{ px}$。所有的保護區域皆由單格內部的「透明安全邊界」進行約束。

* **單格網格尺寸 (Cell Size)**：寬 **`250 px`**，高 **`200 px`**。
* **基本畫布佈局 (Grid Layout)**：$5 \text{ 欄 (Columns)} \times 4 \text{ 列 (Rows)}$ (核心基本功能為前 3 列，第 4 列為跳躍/奔跑，第 5 列為預留)。
* **畫布總解析度 (Canvas Size)**：
  * **3列基本款**：寬 **`1250 px`**，高 **`600 px`**。
  * **4列運動型**：寬 **`1250 px`**，高 **`800 px`**。
  * **5列全功能**：寬 **`1250 px`**，高 **`1000 px`**。

---

## 🎯 二、 角色最大本體尺寸限制與定位基準 (Bounding Box & Anchor)

為了保證不同體型的寵物在切換動作時**不抖動、不懸空、不穿底、不溢出到相鄰影格**，必須對單格內的角色繪製範圍進行嚴格限制：

### 1. 最大尺寸限制 (Maximum Bounding Box)
* **最大寬度限制 (Max Width)**：**`180 px`** (必須水平居中)。
  * 單格左側與右側必須留有至少 **`35 px` 的完全透明區域**：
    $$\text{左側 } 35\text{px (透明)} + \text{角色本體 } 180\text{px (最大限制)} + \text{右側 } 35\text{px (透明)} = 250\text{px}$$
* **最大高度限制 (Max Height)**：**`160 px`** (相對於地板線向上繪製)。
  * 單格頂部必須留有至少 **`20 px` 的完全透明區域**：
    $$\text{頂部 } 20\text{px (透明)} + \text{角色本體 } 160\text{px (最大限制)} + \text{底部緩衝區 } 20\text{px (透明)} = 200\text{px}$$

### 2. 基準定位點 (Anchor Point)
* **水平中心對齊線 (Horizontal Center)**：每個動作的左右中心點，必須精確對齊單格的 **`X = 125 px`** 處。
* **地板對齊線 (Floor Line)**：寵物站立時的「腳底/腹部接觸面」，必須精確對齊單格的 **`Y = 180 px`** 處。
* **底部緩衝區 (Bottom Buffer)**：地板線下方的 **`20 px`**（$Y = 180$ 至 $Y = 200$）必須為完全透明，僅允許繪製半透明的陰影或角色向下擠壓時的延伸。

## 🏃 四、 第四列特化動作：極速奔跑與物理跳躍 (Run & Jump)

本列為專為**高強度運動狀態**設計的特化網格，高度對齊了 Canvas 的物理引擎：

* **單格網格範圍**：Y: `600 px` ~ `800 px`

| 網格坐標 (欄, 列) | 精確影格範圍 (X, Y) | 動作名稱 | 動作說明 |
| :--- | :--- | :--- | :--- |
| **(0, 3)** | X: 0, Y: 600 | **極速奔跑幀 1 (Run 1)** | 雙腳向後用力蹬地，用於運動模式下的高速奔跑。 |
| **(1, 3)** | X: 250, Y: 600 | **極速奔跑幀 2 (Run 2)** | 身體向前衝，與 Run 1 快速交替播放構成快跑動畫。 |
| **(2, 3)** | X: 500, Y: 600 | **向左跳躍在空中 (Jump Air)** | 身體微縮呈滯空狀態，雙腳離地，用於跳躍頂峰幀。 |
| **(3, 3)** | X: 750, Y: 600 | **空中地面輔助幀 (Air-to-Ground)** | 用於起跳（Launch）或即將落地前拉長身體的過渡幀。 |
| **(4, 3)** | X: 1000, Y: 600 | **向左落地緩衝 (Landing Cushion)** | 雙腳著地且身體向下擠壓以吸收重力衝擊的半蹲幀。 |

### 🔗 連續跳躍 (Jump Sequence) 連接邏輯：
當寵物進行一個物理跳躍時，引擎將以極其流暢的順序連續調用以下影格：
$$\text{向左移動 (Row 3, 3)} \rightarrow \text{空中地面輔助 (Row 4, 3)} \rightarrow \text{跳躍滯空 (Row 4, 2)} \rightarrow \text{空中地面輔助 (Row 4, 3)} \rightarrow \text{落地緩衝 (Row 4, 4)} \rightarrow \text{向左移動 (Row 3, 3)}$$
